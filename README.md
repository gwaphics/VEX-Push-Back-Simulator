# VEX Push Back Simulator

> A physics-based, top-down 2D simulator for the **VEX Robotics 2025–2026 Push Back season** — built in Godot with GDScript.

---

## Overview

The VEX Push Back Simulator lets you practice and perfect your robot performance before hitting the real field. Whether you're a driver sharpening your skills or a programmer building and tuning autonomous routines, this simulator gives you a fast, realistic environment to iterate without touching hardware.

---

## Features

- **Driver Practice** — Practice driving in both Match and Skills modes with accurate field physics
- **Physics Simulation** — Top-down 2D physics engine that realistically models robot movement and game object interactions
- **Built-in Code Editor** — Write, test, and tune autonomous routines directly inside the simulator
- **Auton Tuning** — Iterate on your autonomous paths quickly without needing a physical robot
- **Match & Skills Modes** — Simulate full matches or solo skills runs to prepare for competition

---

## Built With

- **Engine:** [Godot](https://godotengine.org/)
- **Language:** GDScript
- **Season:** VEX Robotics 2025–2026 — *Push Back*

---

## Getting Started

### Prerequisites

- [Godot Engine](https://godotengine.org/download) (version compatible with GDScript 2.0+)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gwaphics/VEX-Push-Back-Simulator.git
   ```

2. Open Godot and select **Import Project**

3. Navigate to the cloned folder and open the `project.godot` file

4. Hit **Play** to launch the simulator

---

## How to Use

### Driver Practice
Select either **Match** or **Skills** mode from the main menu and use your keyboard (or controller) to drive your robot around the Push Back field.

### Autonomous Programming
Open the built-in **Code Editor** from the simulator UI to write autonomous routines. You can run, test, and tune your auton directly in the simulator without restarting.
